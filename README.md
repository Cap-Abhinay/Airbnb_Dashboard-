# Airbnb_Dashboard-
# 🏠 Airbnb Dashboard – Power BI

This project is an interactive **Power BI dashboard** built to explore Airbnb data and understand how listings, prices, hosts, ratings, and reviews vary across different cities.

### 📊 What I Explored

* Airbnb listings and market share
* Pricing across different room types
* Superhost vs non-superhost performance
* City-wise ratings
* Review trends and customer behavior

### 🛠️ Tools Used

* **Power BI**
* **Power Query**
* **DAX**
* **Data Modeling**

### 🎯 What I Learned

Through this project, I practiced **data cleaning, DAX calculations, data modeling, and creating interactive dashboards** that turn raw data into useful insights.
